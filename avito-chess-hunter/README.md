# avito-chess-hunter

Поиск недооценённых шахматных наборов на Avito для собственной коллекции.

## Главный тезис

**Искать надо не редкие модели, а неопознанные лоты.**

Наивная постановка — «найди на Avito наборы, которые на eBay стоят дороже» —
не работает по двум причинам, и вторая важнее первой.

1. Ценовой разрыв между Avito и зарубежными площадками для вывоза — это
   в основном *стоимость конвертации*, а не информационная асимметрия
   (запрет вывоза культурных ценностей старше 100 лет, разрешительный
   порядок для 50–100 лет, оборванные платёжные рельсы). При покупке
   в коллекцию внутри РФ эта нога отпадает — но отпадает и трактовка
   зарубежной цены как «цены, которую я получу». Она остаётся только
   индикатором того, *что редко*.
2. Рынок русского шахматного антиквариата мал и связан: профильные
   дилеры и коллекционерское сообщество вычищают явное быстро.
   Объявления «редкая модель за копейки» в среднем либо уже куплены,
   либо новодел. Остаточная неэффективность сидит в лотах, где
   продавец **не опознал** предмет.

Отсюда целевая функция ранжирования — не ценность модели, а
`незнание продавца x шанс, что предмет старый`, за вычетом штрафов за
дилера и за новодел. Реализация в `score.py`.

## Конвейер

```
queries.yaml ──> scrape.py ──> items.jsonl ──> score.py ──> shortlist.csv
                 (Playwright)                  (текстовый
                                                фильтр, дёшево)
                                                      │
                                                      v
                                         vision_prompt.md + markers.yaml
                                         (vision только по шортлисту)
                                                      │
                                                      v
                                            сообщение продавцу
                                            с запросом решающих фото
```

Порядок неслучаен: vision стоит денег и времени, поэтому применяется к
сотне лотов после дешёвого текстового отсева, а не к десяткам тысяч.

## Запуск

Чтобы конвейер шёл без вашего участия — см. **[SETUP.md](SETUP.md)**:
там разобрано, какие три преграды стоят на пути автономности и почему
облачная сессия не годится, а локальная годится.

```bash
pip install playwright pyyaml
playwright install chromium

# первый раз с окном — пройти капчу руками, cookie сохранится в .browser-profile
python scrape.py --headful --max-pages 2

# полный сбор
python scrape.py --out items.jsonl

# шортлист
python score.py items.jsonl --top 100 > shortlist.csv

# фото только по шортлисту
python fetch_photos.py items.jsonl shortlist.csv --out photos

# либо всё сразу
./run.sh

# проверка логики ранжирования на синтетике
python score.py --selftest
```

## Что здесь не доделано — читать перед использованием

**Селекторы не проверены на живом Avito.** Среда, в которой это писалось,
не имеет сетевого доступа к avito.ru (`curl` отдаёт `code=000`), так что
разбор страницы написан вслепую: сначала пробуется встроенное
JSON-состояние, потом DOM по `data-marker`, при провале сырой HTML
сохраняется в `debug/`. Первый реальный запуск почти наверняка потребует
правки разбора — для этого и нужен дамп.

**Веса в `score.py` не откалиброваны.** Это априорные догадки, а не
измерение. Порядок действий: `python score.py items.jsonl --calibrate`
выдаёт 50 случайных лотов, вы размечаете колонку `verdict`
(`gem`/`maybe`/`no`), после чего веса правятся по разметке. До этого
шортлист — черновик, а не результат.

**`markers.yaml` неполон.** Признаки помечены `grounded` (подтверждены
источником) или `memory` (общие знания, не перепроверены). Два известных
пробела: у паттерна «Баку» геометрия не заполнена вообще, у холмогорской
кости нет ни одной подтверждённой реализованной цены. Причина одна и та
же — `sovietchesssets.com` и `barnebys.com` заблокированы из рабочей
среды. Их надо открыть локально и дозаполнить.

**Фотоанализ не даёт атрибуции, только приоритет.** Решающие признаки
физические. Метод отвечает на вопрос «кого спросить и о чём», а не
«что купить».

## Юридическая рамка

Всё вышеописанное рассчитано на покупку и хранение внутри РФ. Предметы
старше 100 лет, признанные культурной ценностью, вывозу из РФ не
подлежат; для 50–100 лет нужно разрешение (Закон РФ от 15.04.1993
№ 4804-1; с 01.03.2026 действует ФЗ от 31.07.2025 № 304-ФЗ). Если
планы изменятся в сторону перепродажи за рубеж — это отдельный
разговор, конвейер под него не рассчитан.
